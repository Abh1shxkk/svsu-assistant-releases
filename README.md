# SVSU Assistant for Android

The Android app of the **SVSU Knowledge Assistant** for Swami Vivekanand Subharti University, Meerut:
ask about the university's circulars, notices and policies in Hindi, English or Hinglish, and get
answers that cite the exact page and passage, highlighted on the original letter.

This repository only publishes the app. Signing in needs a university staff account.

## Download

Get the newest version from **[Releases](../../releases/latest)**:

| File | For |
|---|---|
| `SVSU-Assistant-…-arm64.apk` | Most phones from the last 8 years. Start with this one. |
| `SVSU-Assistant-…-older-phones.apk` | Older 32-bit phones, if the first one won't install. |
| `SVSU-Assistant-…-universal.apk` | Any phone, if you're unsure (larger). |

## Install

1. Download the file on your Android phone and open it.
2. If Android asks, allow your browser or Files app to **install unknown apps**, then tap **Install**.
3. Sign in with the Login ID and password your administrator gave you.

The app tells you when a newer version is available. Updates install over the old version and you
stay signed in.
